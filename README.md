Decomp of Nightmare Beginning Enhanced based on the [unlocked](https://archive.org/details/sonicexe-nbr-unlocked) version of the game. The source was edited so that it will work in GMS 1.4.9999

Keep in mind, when I made this decomp there weren't really any working GMS1 decompiler scripts for the latest version of UTMT, so I kinda [butchered an existing script](https://github.com/somethingggggggg/UndertaleModTool-ExportToProjectScript) so that it barely works on the newest (at the time) UTMT version.

Don't really expect this to be accurate, made for my [browser port of NBR](https://somethingggggggg.github.io/what/nbr.html)
